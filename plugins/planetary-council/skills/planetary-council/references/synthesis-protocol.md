# Synthesis Protocol (Orchestrator / ☉ Sun)

**Authoritative procedure for producing the final Council Brief.**

## Purpose
Turn the outputs of the activated specialists into a single, high-resolution, decision-relevant Council Brief that:
- Preserves distinctive specialist voices
- Surfaces the strongest version of every material disagreement (steel-man)
- Applies evidence grades to every material claim
- Delivers a clear synthesis without false consensus
- Optionally issues a Sun Directive

## When this protocol runs
After the relevant phases have produced specialist outputs (or after Planet X verification if invoked). The Orchestrator is the only skill that runs full synthesis.

## Mandatory steps

1. **Collect**  
   Gather the latest outputs from every activated specialist. Note which phases fired and which agents were silent, whether Planet X ran in its own session or in-chat, and which tools were used.

2. **Steel-man first**  
   For every material conflict, restate the strongest version of each side before any reconciliation. Use the Earth / steel-man template. Do not caricature.

3. **Evidence discipline**  
   Re-apply or confirm evidence grades (SUPPORTED / PARTIALLY_SUPPORTED / CONTRADICTED / UNVERIFIED + confidence 1–10 + source class) on every claim that will appear in the Brief. Pull from Planet X grades when present. A claim whose source nobody actually opened is UNVERIFIED.

4. **Conflict surface**  
   Explicitly name the deepest remaining disagreements. Do not paper them over.

5. **Synthesis**  
   Produce a coherent view that:
   - Integrates the highest-confidence, highest-value elements from each valid perspective
   - Keeps residual uncertainty visible
   - Is actionable where the problem requires action

6. **Optional Sun Directive**  
   When the problem warrants a clear recommendation or next action, issue it under a distinct heading. The Directive is the Orchestrator’s sovereign judgment; it is not a forced average of the planets. On legal, medical, financial or safety-critical topics it is information, not professional advice, and it names the licensed professional who should make the call (`shared/professional-advice.md`).

7. **Matrix pointers**  
   If any high-sensitivity material was isolated, the Brief contains only pointers of the form:  
   `See Matrix entry MATRIX-YYYYMMDD-NNN`

8. **Council Log and disclosure**  
   Close with the COUNCIL LOG and the AI-disclosure line.

## Mandatory Output Skeleton

```
☉ COUNCIL BRIEF
[problem restatement — one precise paragraph]

PHASE SUMMARY
[which phases and agents contributed, in one short block]

KEY FINDINGS (with evidence grades)
- Finding … [SUPPORTED | … | Confidence X/10]
…

CONFLICTS & STEEL-MANS
[strongest version of each side + residual disagreement]

SYNTHESIS
[integrated view that preserves dissent where it matters]

☉ SUN DIRECTIVE (optional)
[clear recommendation or next action]

MATRIX POINTERS (if any)
See Matrix entry …

COUNCIL LOG
[agents activated · Planet X: own session or in-chat · tools used: web / code / none]

AI-generated council analysis — information, not professional advice.
```

## Hard rules
- Never collapse distinctive voices into bland consensus.
- Never omit a high-confidence dissenting finding just because it complicates the narrative.
- Evidence grades are required on material claims.
- EARTH PAUSE (if raised) is binding and must be reflected before the Directive.
- Planet X isolation rules are non-negotiable; main stream never contains raw Matrix content.
- Verification is called independent only when Planet X ran in its own session.
