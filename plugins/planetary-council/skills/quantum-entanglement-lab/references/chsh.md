# CHSH Inequality and Tsirelson Bound

Classical local-hidden-variable theories obey:

|S| ≤ 2

where S = E(a,b) + E(a,b') + E(a',b) − E(a',b') (or an equivalent sign combination).

Quantum mechanics with the singlet reaches the Tsirelson bound:

|S| = 2√2 ≈ 2.828427

Verified angles for the singlet in this laboratory:
- a = 0
- a' = π/2
- b = π/4
- b' = −π/4

Other optimal sets exist: rotating all four angles together gives the same |S|.

The correlator for the singlet is E(θ_a, θ_b) = −cos(θ_a − θ_b).  
A measured |S| > 2 in a real experiment (Aspect 1982 and later) is evidence against local realism. A simulated value is not: it only shows the code reproduces quantum mechanics' prediction.
