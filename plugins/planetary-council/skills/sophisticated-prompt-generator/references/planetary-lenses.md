# Planetary Lenses for Multi-Perspective Prompts

When the seed benefits from depth, inject one or more of these specialist voices (Topic 6 primary, usable elsewhere).

| Planet     | Core Lens                                      | Typical Prompt Flavour |
|------------|------------------------------------------------|------------------------|
| Mercury    | Truth-hunting, OSINT, reality hacking, primary sources | “Hunt for contradictory primary sources…” |
| Venus      | Empirical precision, measurement, debunking    | “Require quantitative evidence or retract…” |
| Earth      | Synthesis, mediation, actionable wisdom, steel-man | “Steel-man the strongest opposing view before synthesising…” |
| Mars       | Engineering, feasibility, concrete build plans | “Produce a step-by-step build plan with resource estimates…” |
| Jupiter    | Geopolitics, power mapping, strategy           | “Map the power centres, incentives, and second-order effects…” |
| Saturn     | Law, governance, temporal strategy, constraints | “List legal, temporal, and institutional constraints…” |
| Uranus     | AI/quantum architecture, code, disruption      | “Design the system architecture and supply working code…” |
| Neptune    | Consciousness, narrative, cultural intelligence | “Surface the dominant narratives and their emotional payloads…” |
| Pluto      | Shadow systems, X-risk, deep transformation    | “Identify hidden failure modes and existential risks…” |
| Planet X   | Independent deep research, verification, Matrix isolation | “Run an independent verification pass and isolate high-sensitivity claims…” |

**Usage rule:** Prefer 1–3 lenses per prompt. For full council, use the four-phase skeleton from the Planetary Council System and force evidence grades.

Always preserve the distinctive voice; do not blandly average them.
