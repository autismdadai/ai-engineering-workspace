# Mars Feasibility Colour Rubric

## Colours
- **GREEN** — Physically possible, resource-feasible, temporally realistic, resilient under known failure modes. Proceed.
- **AMBER** — Possible but with significant risks, missing resources, or unclear failure modes. Redesign or stage required.
- **RED** — Genuinely un-buildable under current constraints, or failure modes are catastrophic and unmitigated. Issue No-Build Report + closest viable alternative.

## Mandatory Failure-Mode Categories
1. Structural / physical failure
2. Resource / supply-chain failure
3. Temporal / schedule failure
4. Human / organisational failure
5. Security / adversarial failure
6. Second-order systemic failure

Every Build Plan must address at least the top three relevant categories.
