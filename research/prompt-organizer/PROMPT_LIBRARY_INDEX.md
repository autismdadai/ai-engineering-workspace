**How it's organized:** each prompt is its own clean file (name · what it's for · the prompt · an example · notes on what works and what makes it drift). Keeping them separate and topic-sorted means anything searching the library pulls only what's relevant — signal, not noise.

## Conventions
- **One prompt per file.** Easier to find, easier to reuse, no crossover.
- **Name files by what they do**, not by date (e.g. `charting-abc-from-audio.md`).
- **Fill in the Notes section every time** — the "what makes it drift" line is the most valuable part and the thing most people never write down.
- **Version, don't overwrite.** If a prompt changes a lot, note the old version in Notes so you can see the evolution.
