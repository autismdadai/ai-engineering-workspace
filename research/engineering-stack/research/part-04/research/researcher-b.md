Minimum size for explicit caches also not stated (page says it varies by model). Pricing page shows one "context caching" price; whether implicit hits are billed the same as explicit hits is not stated (0.1x on every model listed).

## Where sources disagree
- Rate limits: Anthropic (B21) excludes cache reads from ITPM for most models; OpenAI's own API counts cached input toward TPM (B35); AWS Bedrock says cached input on its OpenAI models does NOT count toward input-TPM (B50). Platform-specific.
- OpenAI write surcharge: none on earlier models, 1.25x on GPT-5.6+ (B28). The 2026-10-12 note was missing the 5.6+ surcharge.
- Anthropic minimum: "512 on 5.x" is too broad; Sonnet 5 is 1,024 (B17).
- Lookback: Anthropic "20 positions" (tool_use runs count as one) vs Bedrock "approximately 20 content blocks" (B11, B49).
- Lumer et al. abstract (cost 41-80%, TTFT 13-31%) vs its own table (cost 28-81%, TTFT -8.8 to 30.9%) (B74).
- Song 2607.15516 reports probabilistic, two-tier hit behaviour on Sonnet 4.6 (~3,500-token threshold, ~0.83 hit rate) vs Anthropic docs' deterministic 1,024-token minimum and exact-match rule (B76 vs B17). Unreplicated.
- Vendor cost claims ("discounted up to 95%", OpenAI B27) are list-price ratios, not measured savings; the one independent study measured 28-81% cost cuts and -8.8 to +30.9% TTFT change, depending on model and strategy (B73).
