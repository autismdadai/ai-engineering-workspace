## (c) Claims commonly repeated online that the sources don't support

1. "Claude computer use needs the `computer-use-2025-01-24` beta header." Only for older tool versions. The current toolset needs no header, and on the Claude API and Google Cloud, Claude 5.5 models return an error for the older versions (C01, C03).
2. "Anthropic recommends 1024x768." That is the reference repo's advice (C12). The current docs list 1024x768, 1280x720, 1280x800 and 1366x768 by use case, and warn against going above 1920x1080 (C10).
3. "Claude Opus 5.5 scores 81.8% on OSWorld, beating the 72% human baseline." The 81.8% is an OSWorld 2.1 partial score, reported by the vendor (C50). The 72.36% figure is for humans on the original 369-task OSWorld (C44). OSWorld 2.0's best binary completion is 20.6% (Opus 4.8, C49). These three numbers can't be compared.
4. "OSWorld scores are comparable over time." Anthropic's own chart switches from OSWorld to OSWorld-Verified at Sonnet 4.5 (C47), and Anthropic changed its harness and re-scored Opus 4.7 to 82.3% (C48).
5. "OpenAI computer use returns safety checks like `malicious_instructions`, `irrelevant_domain`, `sensitive_domain` that you must acknowledge." The current guides don't mention them. The SDK still has a `pending_safety_checks` field with a free-text `code` (C30). The named codes weren't found in any source I opened.
6. "OpenAI's computer use model is `computer-use-preview`." That is the legacy path. GA uses tool type `computer` with newer models, and OpenAI now recommends code execution for GPT-6 Astra (C24, C25, C28).
7. "Gemini computer use only works in browsers." That was true of the Oct 2025 Gemini 2.5 model (C42). Current docs and SDK list browser, mobile and desktop environments (C37). How well desktop works wasn't checked.
8. "Classifiers / safety services solve prompt injection." Anthropic says the problem is "far from a solved problem" and a 1% ASR "still represents meaningful risk" (C56). Its classifiers are "not ideal" without a human in the loop (C19). Google's detection is off by default (C41).
9. "86% of web agents get hijacked." The pop-up 86% counts clicks on the pop-up (C53). The WASP 86% counts partial success, and full attacker goals are often not completed (C55).
10. "Claude in Chrome has an 11.2% injection success rate" (or "1%") with no date or setting given. 11.2% is from Aug 2025, autonomous mode, 123 internal cases (C57). 1% is Opus 4.5, Nov 2025, adaptive attacker with 100 attempts (C56).
11. "OSWorld has 361 tasks" vs "369 tasks." Both are real: 369 in total, 361 without the 8 Google Drive tasks (C45).
12. "Playwright MCP is cheaper than screenshots." The README says it avoids vision. It also says accessibility trees are "verbose" and that the CLI is more token-efficient (C60). There's no measured comparison.
