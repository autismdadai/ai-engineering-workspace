## Surprises

1. LLM Guard (Protect AI) was archived on 2026-07-08, including its Hugging Face models (G39). Any text recommending it needs a warning.
2. NeMo Guardrails now sends anonymous usage telemetry to NVIDIA by default, with startup event plus 10-minute heartbeats (G28). Readers should set DO_NOT_TRACK=1 or NEMO_GUARDRAILS_NO_USAGE_STATS=1.
3. Guardrails AI's `configure` defaults turn on both vendor metrics and remote inference, which sends validated text to the vendor's hub API (G37, G38).
4. LlamaFirewall's PromptGuard path truncates at 512 tokens instead of chunking, against Prompt Guard 2's own card advice (G20).
5. LlamaFirewall's AlignmentCheck is not local by default: it calls Llama 4 Maverick on Together AI (G19).
6. Independent results are much worse than vendor ones: Llama Guard 4 FNR 0.658 (PwC, G44) vs Meta's 69% recall; Qwen3Guard drops from 91.0% to 33.8% on novel attacks (G53).
7. Guard LLMs are expensive relative to encoders: about 187x lower throughput for Llama Guard 4 than a 150M encoder (G45).
8. Anthropic's 2026 classifiers cut overhead from 23.7% to about 1% and benign refusals from 0.38% to 0.05% (vendor figures, G48).
9. PurpleLlama's top-level README licence table is stale (stops at Llama Guard 3 / Prompt Guard 1).
