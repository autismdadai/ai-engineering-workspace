## Claims

B001. [3.6 Agent memory: what the research means by it] **CoALA's four kinds.** The Cognitive Architectures for Language Agents framework (TMLR 2024) divides an agent's memory into working memory ("active and readily available information ... for the current decision cycle") and three long-term kinds: episodic ("experience from earlier decision cycles"), semantic ("an agent's knowledge about the world and itself") and procedural .  SOURCES: COA
B002. [3.6 Agent memory: what the research means by it] CoALA: "Language agents contain two forms of procedural memory: implicit knowledge stored in the LLM weights, and explicit knowledge written in the agent's code" .  SOURCES: COA
B003. [3.6 Agent memory: what the research means by it] It warns that letting an agent write to procedural memory is "significantly riskier than writing to episodic or semantic memory" .  SOURCES: COA
B004. [3.6 Agent memory: what the research means by it] MemGPT gave the model function calls to move text between its context and outside storage, "the illusion of an infinite context" .  SOURCES: MGP
B005. [3.6 Agent memory: what the research means by it] Memory work can happen during the reply, with the model calling memory tools (Anthropic's memory tool, MemGPT) , or in the background: Letta's retired server had an option that moves memory management "to a background agent thread", Letta Code's "dreaming" uses "background subagents" after a set number of steps or when the context is compacted, and LangMem has a background memory manager .  SOURCES: AMT, MGP, LET, LTC, LMM
