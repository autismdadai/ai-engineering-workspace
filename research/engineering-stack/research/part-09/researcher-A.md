## (c) Facts the lab must match

A small standard-library workflow engine should reproduce or explicitly contrast these:

1. Checkpoint at step boundaries, not mid-function. On resume after a pause, failure or retry, the interrupted node runs again from the start of its function; code before the pause runs again (LGD graph-api.mdx L772; LGS interrupt docstring).
2. Siblings that finished in a failed step are not re-run (pending writes, LGD checkpointers.mdx L67). Optional for the lab, but if skipped, say so.
3. Resume values for multiple pauses in one node are matched by position (index), so pause order must not change (LGD interrupts).
4. Durability modes to contrast: "exit", "async" (LangGraph default), "sync" (LGS types.py L98; main.py L2696). A lab using "write before next step" is implementing "sync".
5. State keyed by a thread id; no thread id, no resume (LGD checkpointers.mdx L37-39).
6. Step limit: raise an error when exceeded. LangGraph Python 1.2.15 default is 10007 super-steps (source), not 25 and not the 1000 the docs say; error type GraphRecursionError (a RecursionError) with message "Recursion limit of {n} reached without hitting a stop condition." A lab may choose a small limit such as 25 but must not claim it is LangGraph's current default.
7. LangGraph RetryPolicy defaults: initial 0.5 s, factor 2.0, max interval 128 s, max_attempts 3 including the first, jitter on.
8. Temporal default activity retry: initial 1 s, coefficient 2.0, max interval 100 s (100 x initial), unlimited attempts (0 = unlimited). Workflows: no retry policy by default.
9. Anthropic and OpenAI Python SDKs: 2 retries (3 attempts total), base 0.5 s doubling, cap 8 s, delay multiplied by a random 0.75 to 1.0; retry 408, 409, 429, 5xx; honour retry-after (openai only up to 120 s).
10. Full jitter: `sleep = random.uniform(0, min(cap, base * 2**attempt))` (AWC). Equal jitter: `v/2 + uniform(0, v/2)`. Decorrelated: `min(cap, uniform(base, prev*3))`.
11. Idempotency keys: same key + same parameters returns the stored first result (including a stored 500 in Stripe v1); different parameters with the same key is an error; Stripe may prune keys after 24 hours. A lab key store should show the duplicate-suppression and the mismatch error.
12. Effectively once = at-least-once execution plus idempotent effects (Temporal: activity "observed as completed exactly once" but "may be executed multiple times"; Celery acks_late: "may be executed multiple times ... Make sure your tasks are idempotent").
13. Celery contrast: default ack before execution (a crashed task is not re-run), acks_late ack after (crashed task redelivered after the visibility timeout, 1 hour on Redis).
14. Human approval: pause returns a serializable state; approve or reject is applied to that state; resume re-enters the paused step. OpenAI Agents SDK: max_turns default 10. Claude Agent SDK: hooks run first; auto-approved calls never reach canUseTool.
15. Event history ceiling to cite if the lab logs events: Temporal 51,200 events or 50 MiB per execution (warn at 10,240 / 10 MiB).
