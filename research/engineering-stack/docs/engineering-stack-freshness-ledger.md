Rows about licences and law are information, not legal advice.*

## How to use this ledger

- **Before writing a part,** re-check every row the part uses ("Used in"). Before the Phase 5 assembly, re-check them all.
- **When a row changes,** update its value and date here first, then the claim-ledger rows and parts it lists.
- **Rows with a scheduled change** have a "Re-check after" date in Section 1.
- **Package versions** come from the registries, not from memory. Section 7 has the script and commands that produced Sections 2 to 4; re-run them rather than editing numbers by hand.

## 7. Re-checking

**Python packages.** Save as `pypi_fresh.py` and run `python pypi_fresh.py vllm langgraph crewai` (any package names). It uses only the standard library, reads nothing but PyPI's public JSON API, and prints one line per package: name, version, release date, licence, Python requirement. It ran on October 9, 2026 (Python 3.13.16, Linux) and produced Section 2 [T]; it ran again on October 12, 2026 for Section 8, on October 13, 2026 for Section 11, on October 14, 2026 for Section 12, and on October 26, 2026 (Python 3.13.16, Windows) for all of Section 2 [T]. `research/part-11/tools/ledger_compare.py` compares its output with Section 2, column by column.

```python
"""Print version, release date, licence and Python requirement from PyPI."""
import json
import sys
import urllib.request

for name in sys.argv[1:]:
    try:
        url = f"https://pypi.org/pypi/{name}/json"
        with urllib.request.urlopen(url, timeout=30) as response:
            data = json.load(response)
        info = data["info"]
        version = info["version"]
        files = data["releases"].get(version) or []
        released = min((f["upload_time_iso_8601"] for f in files), default="?")[:10]
        licence = (info.get("license_expression") or info.get("license") or "").strip()
        licence = licence.splitlines()[0][:40] if licence else ""
        if not licence:  # fall back to the licence classifiers
            classifiers = [c.split("::")[-1].strip()
                           for c in info.get("classifiers", []) if c.startswith("License")]
            licence = ";".join(classifiers)[:40] or "?"
        python = info.get("requires_python") or ""
        print(" | ".join([name, version, released, licence, python]))
    except Exception as error:  # a missing package or network error
        print(" | ".join([name, "ERROR", str(error)[:60], "", ""]))
```

**npm packages.** `npm view <package> version license time.modified`

**GitHub tags.** `git ls-remote --tags https://github.com/<owner>/<repo>.git`, then sort the tag names. llama.cpp has thousands of build tags, so sort the `b` tags numerically.

**Pages.** Open the "Re-check at" page in Section 1 and compare it with the row. Record the new date even when nothing changed.
