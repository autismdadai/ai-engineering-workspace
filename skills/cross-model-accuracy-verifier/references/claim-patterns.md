# Common Fabrication Patterns
Read when a claim looks suspicious.
1. **Plausible fabrication**: Specific details that sound right but do not exist (fake paper titles, invented statistics).
2. **Confident extrapolation**: "Studies show...", "Experts agree..." with no named source. Status: almost always PARTIALLY_SUPPORTED or UNVERIFIED.
3. **Outdated fact presented as current**: Numbers, API limits, or product names that were true months ago.
4. **Citation hallucination**: Real-looking DOIs, arXiv IDs, or GitHub repos that return 404.
5. **Scope creep inside a claim**: A narrow true statement is expanded into a broader false one.
6. **Self-consistency trap**: The same model is asked to verify its own earlier output.
